A round-based tactical FPS in the style Counter-Strike made famous: two teams, short rounds won by eliminating the other team, money between rounds to buy weapons, and gunfire where accuracy counts more than speed. Single-player against bots, running offline in the browser on three.js.

You plus two friendly bots (Ghost, Viper) vs three enemy bots (Rook, Havoc, Blitz). First to 5 round wins takes the match. Earn money for kills and round wins, spend it on rifles, SMGs and armor between rounds.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click Deploy, WASD to move, mouse to look, click to shoot, R to reload, B for the buy menu between rounds.
